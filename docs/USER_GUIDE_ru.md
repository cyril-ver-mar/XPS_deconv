# XPS-Deconv — Руководство пользователя

**Приложение:** XPS-Deconv  
**Назначение:** деконволюция XPS-спектров из файлов Thermo Scientific **VGD**.

---

## 1. Зачем это приложение

XPS-Deconv даёт воспроизводимый путь от **VGD** к фиту пиков:

1. Много спектров в одном **проекте**  
2. Обрезка ROI, **baseline**, опциональный **denoise**  
3. Фиты **Gaussian / Lorentzian / Voigt / PseudoVoigt**  
4. Сравнение вариантов и экспорт  

Научная логика — в `src/core/`; страницы Streamlit только управляют интерфейсом.

## 2. Установка и запуск «с нуля»

### macOS / Linux

```bash
./install.sh    # venv Python 3.11 + зависимости
./run.sh        # Streamlit → http://localhost:8501
```

### Windows

```bat
install.bat
run.bat
```

Скрипты показывают цветные шаги и **понятные ошибки** (нет Python 3.11, нет venv, сбой pip и т.д.).

Тесты (по желанию):

```bash
./venv/bin/python -m pytest tests/ -q
```

## 4. Типичный сценарий

1. **Импорт** — проект → VGD → активный спектр  
2. **Обрезка** (или Интерактив) — ROI по уровню  
3. **Базовая линия** — Превью → **Применить**  
4. **Деконволюция** или **Интерактив** — пики из библиотеки (tolerance 0 = фиксированный центр) → Запуск  
5. **Последовательность** — сравнить варианты  
6. **Экспорт** — таблицы и рисунки  

Подсказки — иконки ❔.

## 5. Архитектура (5 слоёв)

```text
pages / ui  →  services  →  db  →  core  →  utils
```

| Слой | Путь | Роль |
|------|------|------|
| L1 | `src/utils/` | пути, i18n, отмена |
| L2 | `src/core/` | VGD, baseline, шум, фитинг — **без Streamlit** |
| L3 | `src/db/` | SQLite-индекс |
| L4 | `src/services/` | импорт, анализ, проекты, библиотека, экспорт |
| L5 | `src/ui/`, `pages/` | только UI |

## 6. Краткая наука

- **Baseline:** медиана шума в фоновых окнах (+ Shirley, Tougaard, …).  
- **Превью ≠ Применить.**  
- **Tolerance = 0** — центр зафиксирован.  
- **Метрики:** R, R², RMSE, χ²_red.  
- **Панель неопределённости:** чёрный = данные, красный = локальное среднее, зелёный = ±n·σ; фиолетовый = сумма **выбранных** пиков; % = доля точек с \|данные − сумма\| ≤ n·σ.  

Подробности: `docs/DECISIONS.md`.

## 8. Если что-то сломалось

| Симптом | Что сделать |
|---------|-------------|
| Нет Python 3.11 | Установить 3.11; Windows: `py -3.11`; macOS: `brew install python@3.11` |
| Нет venv | Сначала `install.sh` / `install.bat` |
| pip упал | Сеть, обновить pip, повторить install |
| Порт 8501 занят | Остановить другой Streamlit |
| Ошибки импорта после git pull | Снова запустить install |
| Не видно фит на графике | **Показать все данные** в настройках графика |
| Нужна картинка для статьи | **Настройки графика → Оформление** (шрифты, подписи осей, цвета, толщины — сразу на графике), затем **Экспорт**: PNG / JPEG / TIFF, дюймы + DPI (matplotlib, без браузера) |
| Баннер обновления | Файл `GITHUB_REPO`; к релизу на GitHub прикрепить `XPS-Deconv-standalone-*.zip` |
| Нет баннера / «не удалось проверить GitHub» | **Настройки → Обновления**. Приложение различает нет сети, таймаут, SSL/прокси, HTTP 404 (нет релизов) и лимит запросов. Кнопка **Проверить обновления сейчас**. |
| Первая установка (без копирования всего проекта) | Запустить `standalone_version/install_xps_deconv.sh` (или `.bat`) в нужной папке; ввести `YES` |
| Нет новых встроенных пиков в UI | Библиотека пиков → **Восстановить всю библиотеку** (или удалить `data/peak_library.json`) |
